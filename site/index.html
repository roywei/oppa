Open Personal Assistant

Your assistant.
Your way.

OPPA is a self-hosted assistant for you and your household. It runs on your Mac with your Claude Code or Codex subscription and keeps your memory in a private Git repository you own. It is under active construction.

One conversation, wherever you are.

Talk to it in web chat or by iMessage. The people you register can too, each with their own role.

Memory you own

Notes are Markdown in a private Git repository. Public knowledge goes in a separate wiki.

Made for a household

Partners, children and grandparents each get a role, in direct chats and in family groups.

Reminders and routines

Reminders, daily briefings and background tasks. Once something is connected, it checks in twice a day.

Your harness

Your turns use the accounts, MCP servers and plugins you connected to Claude Code or Codex. You choose how far it may act.

Grows by building

Ask for something new, like your lights or your car, and it writes a script and a skill, then reuses them.

On your own Mac

No API keys of its own and no copied credentials. It uses your CLI's existing sign-in.

Set up in one conversation.

Open the checkout in Claude Code or Codex and ask it to set up OPPA. The agent does the rest.

  1. The agent checks prerequisites, builds OPPA, creates your instance and installs the service.
  2. You answer a few questions, such as which connections you want and your phone number, grant Full Disk Access to one file and click Allow on the macOS dialogs.
  3. You send the assistant one text from your phone. It answers.
git clone https://github.com/roywei/oppa && cd oppa
